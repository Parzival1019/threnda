domains, RFC 5737 documentation addresses). Used by the ten-minute demo in
[docs/pilot/demo-forgatokonyv.md](../../docs/pilot/demo-forgatokonyv.md).

| File | Use in the demo |
| --- | --- |
| `harbor-webapp-pentest.csv` | Step 2 — import 7 findings into the new Harbor project |
